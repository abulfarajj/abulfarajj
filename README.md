# Elma'mun — fundev portfolio

A custom portfolio built with Vite, TypeScript, HTML, and CSS. The visual direction is original: muted olive, ash, and charcoal tones, a programmer seen from behind at a desk, and a large monitor that acts as the focal point.

## Live typing scene
The hero is a single SVG illustration with one coordinate system (monitor, desk, keyboard, chair, presenter, arms, and hands). The monitor types a C# profile line by line: handle, fundev role, the featured NUNSA-FUD project, the stack, languages, and interests. Air-current motion is on by default and can be switched off with the toggle under the scene.

## Run locally
Install Node.js, then run `npm install` and `npm run dev`.

## Deploy to Netlify
The included `netlify.toml` uses `npm run build` and publishes `dist`.
